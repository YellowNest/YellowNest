# YellowNest

Independent open-source developer and contributor focused on Linux, networking, self-hosting, smart home systems and practical software engineering.

I tend to work on problems that start with *"this should work"* and end somewhere deep in networking, containers, APIs, device discovery, frontend behavior or platform-specific edge cases.

## How I work

I prefer practical fixes over theoretical ones:

1. reproduce the problem
2. trace the real root cause
3. understand the surrounding behavior
4. implement the smallest reliable fix
5. test for regressions
6. contribute it upstream when it benefits others

Most of my work comes from running real systems, finding rough edges and fixing the things I would otherwise have to live with.
